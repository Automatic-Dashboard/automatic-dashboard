# Sécurité

Automatic Dashboard tourne dans votre Home Assistant, avec les droits de l'utilisateur connecté. L'intégration ne crée aucune entité, n'ouvre aucun accès et n'envoie aucune donnée hors de Home Assistant ; le tableau lit seulement ce que l'interface de Home Assistant lui fournit.

## Signaler une faille

**Jamais dans un ticket public.** Utilisez le signalement privé de GitHub : onglet *Security*, puis *Report a vulnerability*, sur [Automatic-Dashboard/automatic-dashboard](https://github.com/Automatic-Dashboard/automatic-dashboard/security/advisories/new).

Décrivez ce que vous avez trouvé et comment le reproduire. Vous aurez une réponse sous une semaine, puis un correctif publié dans une nouvelle version, avec votre nom si vous le souhaitez.

## Versions suivies

Seule la dernière version reçoit des correctifs : mettez Automatic Dashboard à jour depuis HACS.

---

*In English: never report a vulnerability in a public issue. Use GitHub's private reporting (Security tab, "Report a vulnerability"). You will get an answer within a week. Only the latest version receives fixes.*
